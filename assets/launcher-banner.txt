    [ 这个黑窗口就是控制台本体，千万别关 ]

    浏览器稍后会自动打开控制台网页。
    关掉本窗口 = 关掉控制台，网页随即连不上。

  ----------------------------------------------------------------
    第一次用？先按顺序做两件事，再回来双击本文件：

      第一步  双击  1-验证密钥.bat    填 DeepSeek API Key
      第二步  双击  2-扫码登录.bat    用手机抖音扫码

    出问题先双击  0-环境自检.bat ，它会逐条告诉你缺什么。
