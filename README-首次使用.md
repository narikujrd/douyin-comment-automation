# 抖音评论自动回复 · 使用指南

一款**在自己电脑上运行**的抖音评论自动回复工具：读取创作者中心的未回复评论 → 本地规则 + 大模型判定 → 生成回复 → 在同一个浏览器会话里发送。

> 不联网中转、不上传账号、不托管数据。所有东西都在你这台机器上。

## 一、三步跑起来

| 步 | 做什么 | 怎么做 |
|---|---|---|
| 1 | 填 API Key | 双击 `1-验证密钥.bat` → 记事本自动打开密钥文件 → 把 `sk-填你自己的key` 换成真实 key → Ctrl+S → 回黑窗口回车。**没 key 也能开控制台**，只是不能生成回复 |
| 2 | 扫码登录 | 双击 `2-扫码登录.bat` → 弹出浏览器 → 手机抖音扫码 → 回黑窗口回车。登录态存在本机，过期重跑一次即可 |
| 3 | 打开控制台 | 双击 **`▶ 抖音回复控制台启动器.bat`** → 浏览器自动打开控制台。**黑窗口要一直开着，关掉就等于停掉** |

第一次用建议：第 5 节「试一句话」看效果 → 第 6 节跑一轮「只看不改」→ 确认没问题再点「确认发送」。

控制台地址固定写在 `config/instance.json` 的 `port`（默认 `5190`），只在本机可访问。

## 二、目录里都是什么

| 文件 | 用途 |
|---|---|
| **`▶ 抖音回复控制台启动器.bat`** | **日常入口**，双击就是打开控制台 |
| `3-控制台.bat` | 控制台本体（启动器调用的就是它，两者等价） |
| `0-环境自检.bat` | 出问题先点这个。只读检查 node / 依赖 / 浏览器内核 / 网络 |
| `1-验证密钥.bat` / `2-扫码登录.bat` | 第一次用时的第 1、2 步 |
| `ui/` | 控制台页面与使用指南 |
| `config/` | 全部配置：人设、回复规则、风险策略、话术 |
| `scripts/` | 程序本体 |
| `test/` | 离线自测，不碰你的配置 |
| `tool/` | 抖音操作层：用真实浏览器抓评论、发回复。已随仓库提供 |
| `state/` `logs/` | 运行态与日志，首次运行后生成 |

## 三、控制台每一节管什么

| 节 | 作用 |
|---|---|
| 1 · 运行范围与作品 | 跑哪些视频。默认「只跑最新作品」。每行下面那格填「这条视频在玩什么梗」，填了它，评论区里的玩梗才不会被当成找茬 |
| 2 · 机器人人设 | 决定**怎么说**，不影响**该不该说**。可手填，也可用一句话让 AI 生成 |
| 3 · 风险回复人设 | 风险评论由谁来回。和普通回复是两条独立链路 |
| 4 · 回复规则 | 15 类评论各自的处置方式、自定义不回复规则、字数与数量上限 |
| 5 · 试一句话 | 粘一句话看判定和文案。**不发送、最省钱的检验入口** |
| 6 · 运行 | 手动跑一轮 + 定时自动回复 |
| 7 · 合作待办 | 命中合作/商务/报价的评论**不自动回**，留给你亲自谈 |
| ⚙ 设置（右上角） | API Key、登录状态、浏览器内核、模型、「已判定不回」缓存 |

## 四、每条评论最后只有三种结局

| 结局 | 什么时候 |
|---|---|
| **正常回复** | 判定「无影响」的普通评论，走模型按人设生成 |
| **用模板** | 模型「拿不准」的，拿一句固定话术打岔：不顺着说，也不沉默 |
| **不回复** | 判定「确定有风险」的，直接跳过并记进缓存，下次同样内容不再花钱重判 |

合作待办是唯一例外：它不进上面三种，留给你人工处理。

第 4 节里 15 类评论的默认处置是 **3 类不回复**（政治敏感、涉及未成年人、纯表情）+ **12 类用模板**，可随时改。

## 五、环境要求

| 项 | 要求 |
|---|---|
| Node.js | ≥ 20 |
| 抓取层 `tool/` | **已随仓库提供**，需要在项目根执行一次 `cd tool && npm install`（约 187 个依赖）+ `npx playwright install chromium`。它用 Playwright 驱动真实浏览器，负责打开创作者中心、导出评论、提交回复；本项目只做判定与文案 |
| 浏览器内核 | 若 `0-环境自检.bat` 提示缺失：`node scripts/fetch-chromium.mjs`（约 20–30 分钟） |
| 磁盘 | 约 50 MB；运行后 `tool/comments-output` 会随导出记录增长 |

## 六、密钥与安全

- 密钥**不在项目里**。优先级：环境变量 `DEEPSEEK_API_KEY` > `~/.douyin-automation/secrets.json` > `config/secrets.local.json`。
- 登录态在 `tool/.playwright/douyin-profile/`。它**比密钥更值钱**（等于账号可被操作），别外传、别传网盘。
- **敏感词表不进仓库**。`config/risk-policy.json` 里的政治类信号默认是空的；要启用关键词过滤，把自己的词写进 `config/risk-policy.local.json`（该文件已被 `.gitignore` 挡住），启动时按类别自动合并。不写也能用，只是这类评论改由模型三档判定，每次多花一次调用。
- 日志只写路径与脱敏指纹，不写 key 明文。可跑 `node scripts/check-secrets.mjs` 自查。
- 源码里出现的 `sk-abcdef...` 这类字符串是**测试用假 key**，不是真实密钥。

## 七、出问题先看这里

| 现象 | 怎么办 |
|---|---|
| 「未检测到评论页入口 / 请扫码登录」 | 登录态过期，重跑 `2-扫码登录.bat` |
| 「已有任务在运行」 | 上一轮没跑完，等它结束或关掉控制台窗口重开 |
| 页面红条「版本不一致」 | 页面是旧的，F5 刷新；仍不行关窗口重开 |
| 打不开 / 端口被占用 | 按提示关掉占用者，或改 `config/instance.json` 的 `port` |
| 双击 .bat 一闪就没 | 先跑 `0-环境自检.bat`，它会逐条提示缺什么 |

离线自检（不碰配置、不发请求）：

```bash
node test/self-test-security.mjs      # 安全单测
node test/self-test-no-reply.mjs      # 不回复规则
node test/self-test-risk-personas.mjs # 风险人设库
node scripts/run-batch.mjs            # 只读跑一轮，不发送
```

## 八、仓库里自带什么、不带什么

| 自带 | 不带 |
|---|---|
| 全部判定与生成逻辑、控制台、离线自测 | 政治类敏感词表（放 `risk-policy.local.json`） |
| `tool/` 抓取层（Playwright 驱动真实浏览器） | API Key（存本机 `~/.douyin-automation/`，不进仓库） |
| 1 套示例人设（`小猫`）与配套打岔话术、12 类风险默认处置与通用模板 | 登录态与评论数据（`.gitignore` 挡住） |

示例人设可以直接改，也可以在控制台第 2 节自己新建一套。

## 九、已知限制

- 作品列表只抓「作品管理」里的**视频**，图文 / 合集 / 直播回放不在列表里。
- 运行范围默认「只跑最新作品」，要多作品请改「按勾选」。
- 每轮有总量上限（默认 30 条），超出部分下一轮继续。
- 依赖抖音页面结构，创作者中心改版后需要更新解析逻辑。
