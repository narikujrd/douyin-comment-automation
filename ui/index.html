4回复规则

    
这里决定三件事：每类评论怎么处理（不回复 / 模板回复）、哪些自定义规则不回、一轮最多回多少。具体怎么说由第 2 节的人设决定。


    

      各类评论怎么处理每类二选一：不回复 / 模板回复
      

        

          每一类都自己选：不回复，或模板回复（用固定话术回一句，不调模型、不花钱、不顺着对方说）。
          政治敏感、涉及未成年人同样可以选，默认是「不回复」—— 这两类回了容易被平台当作给内容加权，不确定就别动。
          点每类的「话术 / 反向关键词」可以看这一类的固定话术，也可以配反向关键词（评论里只出现这些词、没有本类的风险词时，按可以回复处理）。
          这里只管「回不回 / 用什么方式回」，具体口吻由第 2 节的人设决定；安全闸门不在这里控制。
        

        

      

    


    

      

        

          
自定义不回复规则

          

            内置类型不够用时，用一句话说清哪类评论不回，AI 把它变成关键词。
            之后每条评论只做本地匹配，不再调模型、不花钱。

回复的数量与长度

      
这几项一起决定「一轮回多少、每条多长、同一句话最多回几次」。改完点最下面「保存规则」，下一轮生效。

      

        

          
          
          

        

        

          
          
          
低于此长度的回复不要。口语短句很正常，别设太大。

        

      

      

        

          
          
          
一轮里所有作品的回复合计上限，到顶自动停止。

        

        

          
          
          
跨所有轮次的累计上限：该视频回复数达到后整个视频跳过。0 = 不限。

        

        

          
          
          
0 = 不限：10 个人都发「666」，这 10 条都会被回。设正数则超出部分跳过。防单个账号刷屏靠「每轮每人最多 3 条」，不靠这里。

        

      

      

        

          
          
        

        
平台「未回复」= 你没直接回过这条根评论，观众在下面互聊不影响这个判定。不勾则恢复旧行为：有回复线程一律跳过（实测会静默漏掉这类评论）。

拿一条评论当场试。走的是和真实发送完全相同的判定与生成流程，所以这里看到什么效果，真跑就是什么效果。不发送任何内容。

    

      

        
        
        

      

      

        
        
      

    

    

      
      
    

    

      
      每次会真实调用一次模型，约几分钱。
    

    

  


  
  

    
6运行

    

      两种跑法共用同一套判定和出口检查，区别只是「手动点一次」还是「按间隔自己跑」。
      处理的作品沿用第 1 节的列表，列表旧了就点那里的「重新拉取列表」。
      建议先用「只看不改」确认效果，再开自动。
    


    

      
手动跑一轮一次会话跑完，不会反复打开创作者中心

      

        
        
        
      

    


    

      
自动回复（挂机模式）打开即先跑一轮，之后按间隔跑

      
打开后，控制台每隔一段时间自动跑一轮「采集 → 裁决 → 发送」：新评论进来不用你点按钮就会被回复。回复与否以抖音创作者中心的「未回复」显示为准；重复/雷同的评论会沿用已回复过的对应文案（同一句最多沿用 3 次，之后换一句），同一内容的评论默认不限回复条数（「回复规则」可设上限）。风险拦截、字数上限等所有规则照常生效。

      

        
        
      

      

        

          
          
          
1–360 分钟（最低 1 分钟，适合盯测）；日常建议 10–30。

        

        

          
          

        

      

      

        
        
      

      

        
        
      

      

        

          
          
        

        

          
          
        

        

          
支持跨午夜：比如 22:00 到 06:00。平时不必手动开关自动模式。

        

      

      

        
        
      

      
只在这个控制台窗口开着的时候生效：关掉窗口 = 自动模式暂停（正在跑的一轮会正常跑完）；重新打开窗口会自动恢复调度。开关记在 config/auto-reply.json。

      
后台运行若连续失败（平台验证码/登录失效），把「后台运行」关掉改用窗口模式排查——窗口模式下失败画面看得见。

    


    

    

  


  
  

    
7合作待办

    

      评论里出现「合作 / 商务 / 报价 / 接广」这类词时，机器一律不自动回复，只把这条评论记到这里，等你亲自去谈。
      这是整个流程的最后一步：采集 → 判定 →（合作类）记进本清单。
      命中过的评论同时写进「已判定不回」缓存（右上角 ⚙ 设置 里能看到条数），下一轮不再重复判定。
      你回过之后，勾一下右边的「我已回复」，这条就从清单里消失；同一条评论不会被重复记回来。
