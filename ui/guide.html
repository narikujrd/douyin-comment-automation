一、三步就能跑起来

1
填 DeepSeek API Key 双击 1-验证密钥.bat → 记事本自动打开密钥文件 → 把 sk-填你自己的key 换成真实 key → Ctrl+S 保存 → 回到黑窗口回车。没有 key 也能开控制台，只是没法生成回复。
2
扫码登录抖音 双击 2-扫码登录.bat → 弹出浏览器 → 用手机抖音扫屏幕上的码 → 在黑窗口回车。登录态存本机，一次能管很久；过期或换号时重跑这一步。
3
打开控制台 双击 ▶ 抖音回复控制台启动器.bat（或 3-控制台.bat）→ 浏览器自动打开网页控制台。黑窗口要一直开着，关掉就等于停掉控制台。
第一次用建议先点第 5 节「试一句话」，看看判定和文案长什么样；再用第 6 节跑一轮「只看不改」；确认没问题再去点「确认发送」。

二、控制台每一节管什么

节作用
1 · 运行范围与作品决定跑哪些视频。默认「只跑最新作品」，要多个就选「按勾选」再逐个勾。每行下面那格填「这条视频在玩什么梗」——填了它，评论区里的玩梗才不会被当成找茬。
2 · 机器人人设决定怎么说，不影响该不该说。可手填，也可用一句话让 AI 生成一套。
3 · 风险回复人设风险类评论由谁来回。和普通回复是两条独立链路，各管各的。
4 · 回复规则15 类评论每类怎么处置（不回复 / 用模板 / 正常回复），外加自定义不回复规则、字数与数量上限。
5 · 试一句话粘一句话进去，看它被判成什么、会回什么。不发送、不花钱检验的唯一入口。
6 · 运行手动跑一轮 + 定时自动回复。跑一轮分「只看不改」和「确认发送」两种。
7 · 合作待办命中合作/商务/报价的评论不自动回，只记在这里等你亲自谈。谈完勾「我已回复」即从清单移除。
⚙ 设置（右上角）API key、登录状态、浏览器内核、模型，以及「已判定不回」缓存。

三、每条评论最后只有三种结局

结局什么时候
正常回复判定「无影响」的普通评论、夸赞、提问、情绪倾诉，走模型按人设生成。
用模板模型「拿不准」的评论，拿一句固定话术打岔：不顺着对方说，也不沉默。
不回复判定「确定有风险」的评论，直接跳过并记进缓存，下次同样内容不再花钱重判。

合作待办是唯一的例外：它不进上面三种，而是留给你人工处理。

四、三件容易踩的事

  • 别关黑窗口。控制台网页只是壳子，真正的进程在那个黑窗口里。关掉 = 停掉，页面会连不上。
  • 登录态比 API key 更值钱。它在 tool/.playwright/douyin-profile/，等于账号可被操作，别拷给别人、别传网盘。
  • 这个网页只在本机能开。地址固定，别人扫不到；但同一台电脑上的其他程序理论上能访问，所以不要把浏览器留给不相干的人。

五、出问题先看这里

现象怎么办
提示「未检测到评论页入口 / 请扫码登录」登录态过期了，重跑 2-扫码登录.bat。
提示「已有任务在运行」上一轮还没跑完。等它结束，或关掉控制台窗口重开。
页面顶部红条「版本不一致」页面是旧的，按 F5 刷新；还不行就关窗口重开控制台。
打不开页面 / 提示端口被占用端口被别的程序占了。按提示关掉占用者，或改 config/instance.json 里的 port。
双击 .bat 一闪就没了先跑 0-环境自检.bat，它会逐条告诉你缺什么。
